# 🏦 Bank Transaction Analysis & Exploratory Data Analysis (EDA)

A comprehensive **Exploratory Data Analysis (EDA)** project that examines financial transaction behavior across customers in a banking ecosystem.
The project leverages data-driven insights to understand **customer behavior, geographic trends, and potential financial anomalies** using real-world banking transaction data.

---

## 🎯 Objective

This project aims to:

* Analyze customer financial behavior based on demographics 📊
* Identify transaction patterns across different regions 🌍
* Detect potential anomalies using behavioral metrics 🔐
* Build a strong foundation for future **fraud detection and risk modeling systems**

---

## 📌 Dataset Overview

* 📦 **Size:** 2,500+ unique transaction records
* 👤 **Features:** Age, occupation, location, transaction amount, account balance
* 🔐 **Security Metrics:** Login attempts, transaction duration, behavioral patterns

---

## 🔍 Key Insights

📍 **Geographic Trends**

* High transaction activity observed in cities like **Fort Worth** and **Los Angeles**
* Regional differences strongly influence transaction volume

👥 **Customer Behavior**

* Spending patterns vary significantly across age groups and occupations
* Certain demographics show consistently higher transaction frequencies

💰 **Financial Patterns**

* Clear distribution trends in account balances and transaction amounts
* Identification of outliers indicating unusual financial activity

🔐 **Security Analysis**

* Login attempt frequency helps highlight potential suspicious behavior
* Transaction duration patterns provide additional anomaly indicators

## 📊 Methodology

The project follows a structured EDA workflow:

### 1️⃣ Data Cleaning

* Handling missing values
* Formatting and type corrections
* Removing inconsistencies

### 2️⃣ Data Exploration

* Statistical summaries of key variables
* Distribution analysis of financial features

### 3️⃣ Visualization

* Heatmaps, histograms, and bar charts
* Geographic and demographic trend analysis

### 4️⃣ Insight Generation

* Behavioral pattern identification
* Detection of anomalies and outliers
