# Bank Transaction Analysis & EDA

This project focuses on the detailed analysis of financial transaction patterns within a banking ecosystem. By processing a dataset of over 2,500 unique records, the analysis investigates the relationship between customer demographics (age, occupation, and location) and financial behavior (transaction amounts and account balances).

Beyond simple statistics, the project utilizes Exploratory Data Analysis (EDA) to identify high-volume geographic hubs like Fort Worth and Los Angeles and evaluates security-related metrics such as login attempts and transaction durations. The goal is to provide a data-driven foundation for understanding customer personas and detecting potential financial anomalies using Python's robust data science stack.
